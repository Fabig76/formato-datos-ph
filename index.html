📋 Formato de Datos PH

Plantilla reusable para formularios públicos de residentes en propiedades horizontales

Empezar en 30 min Ver ejemplo en vivo Ver en GitHub

¿Qué es?

Sistema completo para crear un formulario web público (accedido vía QR) que permite a residentes y propietarios de cualquier propiedad horizontal en Colombia actualizar sus datos en un Google Sheet.

Cumple con la Ley 1581 de 2012 (Protección de Datos Personales) y el Decreto 768 de 2025 (Censo de Animales de Compañía).

Demo en vivo Cerro Azul

¿Cómo lo implemento en mi PH?

Resumen rápido

  1. Crear Google Sheet con 138 columnas (encabezados en la fila 1)
  2. Crear repo GitHub (público) y subir los archivos de la carpeta implementaciones/cerro-azul/web/
  3. Activar GitHub Pages en Settings → Pages → branch main
  4. Crear Apps Script en script.google.com y pegar el contenido de Codigo.gs
  5. Desplegar Apps Script como Web App ("Cualquier persona")
  6. Pegar la URL del Web App en js/app.js
  7. Generar QR con python scripts/generar-qr.py "URL"
  8. Distribuir a residentes

Características

  • ✅ 100% gratis: GitHub Pages + Apps Script + Google Sheets
  • ✅ Sin servidor: Google hospeda todo
  • ✅ QR-friendly: diseño responsive optimizado para celular
  • ✅ Dedupe automático: un apartamento = un solo registro
  • ✅ Edición segura: residente edita con N° de Formulario + Apto
  • ✅ Auditable: timestamp de creación y última edición
  • ✅ Personalizable: logo, colores, textos de tu PH
  • ✅ 30-45 min de tiempo de implementación
  • ✅ Cero mantenimiento de infraestructura

Limitaciones conocidas

  • ⚠️ El QR es público — las validaciones evitan datos vacíos pero NO impiden datos falsos. La admin debe revisar el Sheet periódicamente.
  • ⚠️ El residente debe recordar su N° de Formulario para editar.
  • ⚠️ No soporta adjuntar archivos (fotos de mascotas, etc.).
  • ⚠️ Diseñado para propiedades residenciales colombianas; otros países requieren adaptación de textos legales.
